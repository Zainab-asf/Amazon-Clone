# Amazon Clone

A front-end clone of the Amazon homepage, built with plain HTML and CSS as a layout and styling exercise.

## Features

- Navigation bar with logo, delivery address, search bar, language, sign-in, returns and cart sections
- Grid of product category cards with images
- "Back to Top" link and multi-column footer
- Flexbox layouts throughout
- Responsive breakpoint at 768 px for tablets and phones
- Font Awesome icons

## Project Files

| File | Purpose |
|---|---|
| `Index.html` | Page markup |
| `Style.css` | Styles and responsive rules |
| `Asset.rar` | Images used by the page |

## Running Locally

1. Clone the repository.
2. Extract `Asset.rar` into the project folder so there is an `Asset/` directory next to `Index.html`.
3. Open `Index.html` in a browser.

## Tech Stack

HTML5 · CSS3 · Font Awesome
